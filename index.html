Connect ke GitHub

Biar perubahan kamu (foto, urutan, teks) beneran ke-simpen ke repo GitHub kamu, tempel token akses di sini. Kalau belum punya:

  1. Buka github.com/settings/personal-access-tokens/new
  2. "Repository access" → pilih Only select repositories → centang wisuda-moodboard
  3. "Permissions" → Repository permissions → Contents → set ke Read and write
  4. Generate token, lalu copy (cuma kelihatan sekali)
  5. Tempel di bawah ini

Token ini disimpen di browser ini aja (gak pernah ketulis ke halaman/repo), jadi nempel terus di semua tab Safari kamu sampai kamu klik Disconnect. Kalau buka dari device/browser lain, tempel lagi di sana.
